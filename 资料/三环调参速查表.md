## 三、与"力控"直接相关的参数（老师的方向）

这台驱动器**原生支持力控、阻抗控制、导纳控制**，不只是"只有位置控制"——能力就在参数表里：

| 控制方式     | 参数                                       | OD 索引                    | 说明                                |
| -------- | ---------------------------------------- | ------------------------ | --------------------------------- |
| 力/力矩闭环   | Force Torque Kp / Ki / Feedforward       | 0x35CC / 0x35CD / 0x35CB | 力-力矩环 PI + 前馈                     |
| 力传感器     | Force Sensor LPF Cutoff Frequency        | 0x3593                   | 力传感器低通截止（本机 N 款无力传感器，此处用电流估计）     |
| 单位       | Force Torque Unit Index                  | 0x35FB                   | 力/力矩显示与指令单位指数（默认 -3，即 m 级）        |
| **阻抗控制** | Force Position Impedance K / B / M       | 0x3588                   | 力-位置阻抗：K 刚度、B 阻尼、M 惯量（虚拟弹簧-质量-阻尼） |
| **导纳控制** | Force Position Admittance K / B / M      | 0x3592                   | 力-位置导纳：受力→生成位置修正，适合柔顺交互           |
| 补偿       | Force Torque Compensation Enable / Table | —                        | 力控力矩补偿表                           |

> 运行模式号（CiA402）：位置=1、速度=3、力矩=4、CSP=8、CSV=9、CST=10、**开环力控=11**、惯量辨识=-12

## 四、调参顺序 checklist（建议流程）

- [ ] **0. 安全**：模组固定牢、输出轴周围清空、48V 极性确认、急停/断电顺手。有抱闸款注意断电状态。
- [ ] **1. 基线记录**：把上面第一张表所有参数当前值抄下来，存成"出厂基线"，随时可回滚。
- [ ] **2. 辨识**（指导书 3.3）：一键辨识 → 存参数。辨识出电角度偏移、相序、电感电阻、转矩常数、转子惯量。
- [ ] **3. 验证电流环**：切力矩模式，给很小的力矩指令，看实际电流是否线性跟随、有无异响 → 确认电流环 OK（通常不用改）。
- [ ] **4. 调速度环**：切速度模式，给阶跃指令，看波形（右键切参数叠加"目标速度/实际速度"）。
  - 从默认 400Hz 起，**每次 +20%~50%**，直到出现超调/振荡/啸叫，然后**回调到 70~80%**。
  - 噪声大 → 加大 Smoothing Factor；啸叫且频率固定 → 用低频振动滤波器/带阻陷波压掉。
- [ ] **5. 调位置环**：切位置模式（先使能再发位置），给位置阶跃，看跟随误差与超调。
  - 逐步加 Position Controller Gain；跟随误差大而稳定有余量 → 优先靠速度前馈（0x3511）。
- [ ] **6. 补摩擦补偿**：测静态摩擦电流 → 填 Static Friction Current → 开 Friction Compensation Enable，从 10% 慢慢加。
- [ ] **7. 惯量/增益切换**：负载惯量变化大时开惯量自适应；需要"到位前减速"手感时用增益切换。
- [ ] **8. 每次改动记录**：参数名 + 旧值 → 新值 + 波形截图。这是给老师汇报和写报告的全部素材。

## 五、安全红线

1. 位置环增益和速度带宽**不能在电机带载转动时大幅突变**，会飞车/冲击。
2. 输出端 11Nm 额定、28Nm 峰值，**堵转或撞限位时电流会顶满**，长时间堵转 = 烧线圈。
3. 出现持续啸叫/剧烈抖动：**立刻失能**，再从低增益重新调，不要硬扛。
4. 每次只改**一个参数**，改完观察，否则不知道是哪个起了作用。
